# المرحلة الثانية — UX/UI

سأنفّذ البنود الستة على دفعتين لأن بعضها (Multilingual + Admin drag-and-drop) أكبر من الباقي.

---

## Batch A — تحسينات سريعة (يوم واحد)

### U1 — تبسيط CTAs في الهيرو
حالياً 3 أزرار متجاورة (شاهد أعمالنا / احسب التسعيرة / ابدأ مشروعك) → ضوضاء بصرية.

**الحل:**
- CTA رئيسي واحد بارز: **"ابدأ مشروعك"** (← /contact)
- CTA ثانوي نصي تحته: **"شاهد أعمالنا →"** (link style)
- زر التسعيرة ينتقل إلى الـ Showreel card الجانبي كـ "احسب تكلفة مشروعك" أسفل البطاقة

### U4 — قسم الإحصائيات بدون سياق
حالياً أرقام مجرّدة (مثلاً "+140") بدون توضيح.

**الحل:**
- إضافة سطر فرعي تحت كل رقم يشرح المعنى (مثل: "علامة تجارية وثقت بنا منذ 2019")
- إضافة tooltip اختياري عند hover للأرقام التي تحتاج تفسير
- ربط القسم بـ headline صغير: "أرقام تحكي قصتنا"

### U25 — صفحة 404 سينمائية مخصصة
حالياً لا توجد notFoundComponent على الـ root.

**الحل:**
- صفحة سينمائية بسيطة: خلفية مظلمة + grain + شريط فيلم
- نص: "Scene not found" / "هذا المشهد غير موجود"
- CTA: العودة للرئيسية + رابط للأعمال
- إضافة `notFoundComponent` في `__root.tsx` + `defaultNotFoundComponent` في `router.tsx`

### U21 — تصنيف المشروع كـ Select بدل نص حر
في لوحة الإدارة، حقل category حالياً Input نصي → يخلق فوضى (film/Film/FILM/فيلم).

**الحل:**
- استبدال الـ Input بـ shadcn Select
- خيارات ثابتة بالإنجليزية كقيم تخزين + label عربي للعرض:
  - `film` — فيلم
  - `documentary` — وثائقي
  - `ads` — إعلان
  - `corporate` — مؤسسي
  - `event` — تغطية فعالية
  - `music-video` — كليب
  - `reel` — ريلز
- نفس الـ Select على فلتر صفحة /portfolio
- migration بسيطة: normalize القيم الموجودة (lowercase) عند الحفظ

## Batch B — أكبر (3–4 أيام)

### U20 — Drag-and-drop لإعادة الترتيب في الـ Admin
**الحل:**
- تثبيت `@dnd-kit/core` + `@dnd-kit/sortable`
- إضافة عمود `sort_order INT` في جدول site_content للمشاريع والعملاء (أو حفظ الترتيب ضمن JSON)
- handle سحب على كل بطاقة في tabs المشاريع والشركاء
- زر "حفظ الترتيب" يحفظ الـ array الجديد عبر serverFn

### Multilingual EN/AR
هذا الأكبر — يحتاج بنية تحتية.

**المقاربة:**
- إضافة `i18next` + `react-i18next`
- ملفان: `src/locales/ar.json` + `src/locales/en.json`
- استخراج كل النصوص الثابتة من الصفحات إلى مفاتيح ترجمة
- toggle لغة في الـ SiteHeader (AR/EN)
- حفظ التفضيل في localStorage + قراءة `navigator.language` للزائر الجديد
- تبديل `dir="rtl"` ↔ `dir="ltr"` على الـ `<html>` ديناميكياً
- للمحتوى الديناميكي (المشاريع، الخدمات، البطل): إضافة حقول `_en` في الـ DB (مثل `title_en`, `desc_en`, `subtitle_en`) + fallback للعربي إذا فارغ
- لوحة الإدارة: حقول مزدوجة AR/EN لكل نص تحريري
- SEO: تحديث `<head>` (title, description, og) بناءً على اللغة + إضافة `<link rel="alternate" hreflang="...">`
- sitemap.xml: إضافة نسخ بكلتا اللغتين

**ملاحظة:** الترجمة لن تكون آلية — سأستخرج الـ keys وأضع نصاً إنجليزياً مبدئياً معقولاً، ولك حرية تعديله من الـ admin أو من ملف `en.json`.
