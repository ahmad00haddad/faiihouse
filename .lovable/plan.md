# خطة التنفيذ — Faii House

## 1) تعديلات نصية وسلوكية فورية
- إزالة كلمة «استوديو/Studio» من كل الصفحات واستبدالها بـ «شركة إنتاج سينمائي / فريق».
- زر **SHOWREEL** يفتح: `https://www.youtube.com/watch?v=yB-VOx0gS54` في تبويب جديد (نفس التصميم).
- تحديث الإحصائيات: **+300 مشروع**، **+140 علامة تجارية**.
- حذف سكشن **THE TEAM** بالكامل من صفحة About.
- إعادة كتابة نص «عن فَيّ»: فريق وأصدقاء من إربد، نعمل معاً كفريق متكامل (لا استوديو).
- في صفحة Contact: حذف **ساعات العمل**.
- في صفحة Portfolio: كل مشروع يحمل رابط **Behance** وعند النقر يفتح في تبويب جديد.
- في الرئيسية: شركاء النجاح يعرض أول 10، وزر **«عرض المزيد»** يكشف الباقي (سأعيد قراءة الدرايف لاستخراج كل اللوغوهات الموجودة — رأيت ~20 لوغو حتى الآن).

## 2) لوحة تحكم Admin
- تفعيل **Lovable Cloud** لتخزين المحتوى بشكل دائم.
- جدول واحد `site_content` يحوي JSON document فيه: services / portfolio / clients / about / contact / stats.
- صفحة `/admin/login` بسيطة: username = `admin` ، password = `admin12345`.
  - التحقق يتم في **Server Function** ضد سرّ بيئي، ثم يصدر توكن جلسة (cookie) صالح لمدة محدودة.
- صفحة `/admin` محمية: تبويبات لإدارة:
  - الخدمات (إضافة/تعديل/حذف عنوان + وصف + أيقونة).
  - المشاريع (صورة + عنوان + تصنيف + رابط Behance).
  - شركاء النجاح (رفع صورة + اسم).
  - النصوص العامة (نبذة، إحصائيات، بيانات التواصل، روابط السوشال).
- رفع الصور عبر Lovable Cloud Storage (bucket public).

## 3) أنيميشن «فينتيج سينمائي» غير مزعج
- تأثير **فلم 35mm**: حبيبات خفيفة (grain) على الأقسام البطلة + flicker خفيف عند التحميل.
- انتقالات صفحات بـ Motion: fade + parallax بسيط للصور.
- **Marquee** متحرك بطيء لشركاء النجاح بدل grid ثابت.
- عند hover على المشاريع: zoom سينمائي + شريط فيلم في الأسفل.
- مؤشر **scroll progress** علوي رفيع بلون primary.
- نص العناوين يظهر بـ split-letters reveal بطيء.

## 4) اقتراحات إضافية (للتنفيذ بعد موافقتك)
- **Light/Dark toggle** (الموقع الآن داكن فقط).
- **WhatsApp floating button** للتواصل السريع.
- **Cookie/Lead capture**: فورم «أرسل بريفك» على Contact يصل بريداً عبر Resend.
- **SEO**: sitemap.xml + robots.txt + meta لكل صفحة بالعربية والإنجليزية.
- **/portfolio/:slug** صفحة تفاصيل مشروع (بدل القفز المباشر للBehance — اختياري).
- **Testimonials** سكشن من شهادات العملاء.
- **Press / Featured in** شريط لوغوهات إعلامية إن وُجدت.
- **Reels Grid** من Instagram عبر embed.
- **Analytics**: تتبع زيارات/نقرات الأزرار.
- **Multilingual EN/AR** toggle.

## تفاصيل تقنية مختصرة
- الـ stack: TanStack Start + Tailwind + Lovable Cloud.
- جدول `site_content` بصف واحد `id=1` يحوي عمود `data jsonb`.
- جدول `admin_sessions` بسيط (token, expires_at) أو cookie موقّع بـ HMAC.
- Storage bucket `media` عام للقراءة.
- كلمة سر الادمن تُخزَّن كسر بيئي `ADMIN_PASSWORD` (افتراضياً `admin12345`).
